Критический CSS встроен в style до ссылки на assets/css/style.v1.css.

## Перед запуском
1. УНП в подвал и политику.
2. Реальные фото объектов вместо сгенерированных.
3. В брифе только «утепление фасадов жилых домов и коттеджей». Остальные шесть работ на странице услуг (откосы, армирование, отделка, ремонт старого утепления) выведены как этапы фасадных работ: нужно подтвердить, что предприятие их выполняет.
4. Подтвердить: выезд за пределы Минска и пригорода, работа зимой, гарантия.
